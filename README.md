# WinTool

Open-source Windows diagnostics, maintenance and optimization toolkit.

WinTool is designed to make Windows diagnostics, maintenance and performance tools easier to understand and use, while keeping changes controlled and reversible whenever possible.

## Features

- PC status and system diagnostics
- Smart alerts
- Smart maintenance
- Gaming optimization
- Recommended privacy settings
- Network and DNS tools
- Windows repair tools
- Driver and hardware utilities
- Software updates with WinGet
- Performance analysis
- WinAnalyzer gaming performance analyzer

## WinAnalyzer

WinAnalyzer is WinTool's gaming analysis module.

It can measure and present information such as:

- Average FPS
- 1% Low FPS
- Minimum detected FPS
- Frame-rate stability
- CPU usage
- Most utilized CPU core
- GPU usage
- RAM usage
- Possible FPS limits / VSync
- Possible CPU or GPU bottlenecks

The main results are designed to be easy to understand, while more technical information remains available separately.

## Safety

WinTool prioritizes controlled changes and diagnostics before modification.

Optimization features are designed to avoid unsafe tweaks such as Realtime process priority, arbitrary CPU affinity changes, HPET/BCD modifications, pagefile disabling or disabling critical Windows services.

Several modifications include backup or restoration mechanisms.
